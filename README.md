# vpngramm 4.7 для Windows 11 (x64)

vpngramm создаёт и обслуживает ваши VPN-серверы:
- покупает VPS в OneProvider;
- ставит VLESS + Reality, VLESS XHTTP, Hysteria2, AmneziaWG и прокси Telegram;
- даёт постоянные ссылки и подписку для Happ;
- ведёт людей, проверки и копии серверов.

Версия для Windows собирается **из того же кода**, что и приложение для Android: общий код лежит в `app/src/main/java`, а модуль `desktop` добавляет к нему окно Windows, хранение настроек и шифрование.

## Как получить программу

**Готовый архив.** Откройте вкладку **Actions** → последний успешный запуск **Windows build** и внизу, в разделе Artifacts, скачайте `vpngramm-4.7-windows-x64`. Дальше:
1. Распакуйте архив целиком: правой кнопкой → «Извлечь все…». Из архива напрямую программа не запустится.
2. Запустите `vpngramm.exe`. Java ставить не нужно — она уже лежит в папке `runtime`.
3. Если Windows покажет «Система Windows защитила ваш компьютер», нажмите «Подробнее» → «Выполнить в любом случае». Так бывает с программами без платной цифровой подписи.

**Собрать самому** (Linux или macOS; нужны JDK 17+, Go 1.22+ для запускатора vpngramm.exe и интернет):
```
./gradlew :desktop:windowsZip      # архив → out/vpngramm-4.7-windows-x64.zip
./gradlew :desktop:test -Pskia=linux-x64
```
Подробнее — в `BUILD_RU.md`.

## Где хранятся данные
Всё лежит в папке `%APPDATA%\vpngramm`:
- `settings.properties` — настройки;
- `secrets.properties` — пароли, SSH-ключ и токены. Они зашифрованы Windows DPAPI: прочитать их может только ваша учётная запись Windows на этом компьютере;
- `known_hosts` — отпечатки серверов, которым вы доверяете.

Серверы между телефоном и компьютером переносятся так: на одном устройстве Главная → ⋮ → «Сохранить копию», на другом — «Восстановить из файла». Копии от Android и от Windows взаимозаменяемы.

## Чем отличается от Android
С версии 4.0 вкладок три и там, и там: Главная, VPS/DNS, Инструменты. Встроенного VPN-клиента больше нет ни в одной версии — подключайтесь через Happ или v2rayN по «Подписке Happ» со страницы «Ссылки» на Главной.

На Главной: «Заменить сервер» переносит сервер на новый VPS или на «Свободный сервер» — туда можно добавить любой сервер по IP и паролю или SSH-ключу. Если переезд прервался, карточка «Переезд не завершён» возвращает всё на прежний сервер.

В «Инструментах»: «Доступ к серверам» (SSH, «Ключи для всех серверов», «Защитить сервер» — файрвол, fail2ban, вход только по ключу) и «Сервис → Произвольный VPS» — установка VPN на любой сервер по паролю или SSH-ключу, без покупки и без добавления на Главную.

| Android | Windows |
|---|---|
| Вход на серверы по аппаратному ключу (Рутокен MFA, YubiKey) в «Инструменты → Доступ к серверам» | Нет: вход по паролю или обычному SSH-ключу |
| «Поделиться» | Текст копируется в буфер обмена, дальше Ctrl+V |
| Пароли в Android Keystore | Пароли шифруются Windows DPAPI |

## Проверка
GitHub Actions проверяет каждую выкладку:
- собирает архив;
- на настоящей Windows прогоняет тесты, включая шифрование DPAPI;
- запускает `vpngramm.exe`, снимает экран, штатно закрывает окно и проверяет, что настройки сохранились.

Снимок и журналы лежат в артефакте `windows-check`.
