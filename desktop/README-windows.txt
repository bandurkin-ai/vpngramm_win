vpngramm 3.5 для Windows 11 (x64)
==================================

vpngramm создаёт и обслуживает ваши VPN-серверы: покупка VPS в OneProvider,
установка VLESS + Reality, VLESS XHTTP, Hysteria2, AmneziaWG и прокси Telegram,
постоянные ссылки и подписка для Happ, люди, проверки и копия серверов.
Это та же программа, что и на Android, только для компьютера.

ЗАПУСК
1. Распакуйте архив целиком: правой кнопкой по zip → «Извлечь все…».
   Запускать прямо из архива нельзя — рядом с программой должна лежать папка runtime.
2. Откройте распакованную папку и запустите vpngramm.exe.
3. При первом запуске Windows может показать «Система Windows защитила ваш компьютер»
   (программа не подписана платным сертификатом). Нажмите «Подробнее» → «Выполнить в любом случае».

Устанавливать Java не нужно: она уже лежит в папке runtime.
Программу можно держать в любой папке, например C:\Программы\vpngramm.

ГДЕ ХРАНЯТСЯ ДАННЫЕ
%APPDATA%\vpngramm  (вставьте эту строку в адресную строку Проводника)
  settings.properties — настройки;
  secrets.properties  — пароли, SSH-ключ и токены. Они зашифрованы средствами
                        Windows (DPAPI): прочитать их может только ваша учётная запись
                        Windows на этом компьютере. На другой компьютер этот файл не переносится —
                        переносите серверы через «Сохранить копию» на Главной.
  known_hosts         — отпечатки серверов, которым вы доверяете.

ПЕРЕНОС С ТЕЛЕФОНА
На телефоне: Главная → ⋮ → «Сохранить копию». Передайте файл на компьютер.
Здесь: Главная → ⋮ → «Восстановить из файла». Копия от Android подходит и наоборот.

ЧЕМ ОТЛИЧАЕТСЯ ОТ ВЕРСИИ ДЛЯ ANDROID
• Встроенного VPN-клиента пока нет. На компьютере подключайтесь через Happ для Windows
  или v2rayN — по ссылкам или подписке (вкладка VPN подскажет, что куда вставить).
• Фонового контроля серверов с уведомлениями нет — проверяйте кнопкой «Проверить» на Главной.
• «Поделиться» копирует текст в буфер обмена — вставьте его в мессенджер (Ctrl+V).

ЕСЛИ НЕ ЗАПУСКАЕТСЯ
• Появилось окно «vpngramm не запустился» — пришлите файл %APPDATA%\vpngramm\launcher.log.
• Если программа упала во время работы, при следующем запуске она покажет отчёт —
  нажмите «Скопировать» и пришлите его. В отчёте нет паролей и ключей.

Удаление: закройте программу и удалите её папку. Чтобы стереть и данные —
удалите ещё папку %APPDATA%\vpngramm.
